# rancipe — วันนี้ทำอะไรกินดี?

เว็บหน้าเดียวช่วยเลือกเมนู มี 2 โหมด: **ล้างตู้เย็น** (ใส่วัตถุดิบที่มี แล้วหาเมนู) และ **กินอะไรดี?** (สุ่มเมนู)

## โครงสร้าง

```
index.html                       หน้าเว็บทั้งหมด (HTML + CSS + JS ในไฟล์เดียว)
data/recipes.csv                 สูตรอาหารทั้งหมด
data/ingredient_aliases.csv      ชื่อเรียกอื่นของวัตถุดิบ เช่น ไข่ไก่ -> ไข่
data/categories.csv              รายชื่อหมวดที่อนุญาต
scripts/validate_data.py         ตรวจข้อมูลก่อน commit
```

เว็บโหลดข้อมูลจากไฟล์ใน `data/` โดยตรง ไม่ได้ดึงจาก Google Sheet แล้ว

## แก้หรือเพิ่มสูตร

แก้ `data/recipes.csv` (เปิดด้วย Excel / Google Sheets / แก้บน GitHub ก็ได้ แล้วบันทึกเป็น CSV แบบ UTF-8)

| คอลัมน์ | ความหมาย |
|---|---|
| `id` | รหัสเมนู ห้ามซ้ำ เช่น `TH041` |
| `menu_name` | ชื่อเมนู |
| `category` | หมวด ต้องตรงกับ `categories.csv` |
| `cuisine` | ชาติอาหาร เช่น `อาหารไทย`, `อาหารญี่ปุ่น` (เว้นว่างได้ ถ้าไม่มีเมนูไหนระบุ ตัวกรองนี้จะไม่แสดง) |
| `main_ingredients` | วัตถุดิบหลักที่ต้องมี คั่นด้วย `,` ใช้ค้นหาในโหมดล้างตู้เย็น |
| `optional_ingredients` | วัตถุดิบเสริม ไม่มีก็ทำได้ (แสดงในหน้ารายละเอียด ไม่ใช้ค้นหา) |
| `instructions` | วิธีทำ ถ้าอยากให้แยกเป็นข้อ ให้ขึ้นบรรทัดใหม่ หรือใส่ `1.` `2.` นำหน้าแต่ละข้อ |
| `cook_time` | เช่น `15 นาที` (ต้องมีตัวเลข ใช้กรอง "ไม่เกิน 10/20 นาที") |
| `difficulty` | `ง่าย` / `กลาง` / `ยาก` |
| `tags` | คำค้นเพิ่ม คั่นด้วย `,` เช่น `เผ็ด, ทำง่าย` |
| `image_url`, `source_url`, `notes` | ยังไม่ได้ใช้ในหน้าเว็บ |

## ตรวจข้อมูลก่อน commit

```
python3 scripts/validate_data.py
```

จะเตือนถ้า id ซ้ำ ช่องจำเป็นว่าง หมวดหรือความยากผิดค่า หรือ `cook_time` ไม่มีตัวเลข

## ลองเปิดในเครื่อง

เบราว์เซอร์ไม่ให้ `fetch` ไฟล์ตอนเปิดด้วยการดับเบิลคลิก (`file://`) ให้เปิดผ่านเซิร์ฟเวอร์เล็ก ๆ แทน

```
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## อัปเดตเว็บ

ต้องอัปโหลดทั้ง `index.html` และโฟลเดอร์ `data/` ขึ้นโฮสต์ (ถ้าตั้ง Git deployment ไว้ จะตามมาเองเมื่อ merge เข้า `main`)
